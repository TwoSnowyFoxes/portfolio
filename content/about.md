## About me

I’m a Data Engineer that focuses on automating boring/redundant manual tasks end-to-end. That means that, in my job, I'm mainly working on large projects that are diverse in tools & solutions. Technical work I've done includes, but is not limited to:

- Creating API's to transfer data
- Creating data models to efficiently transform data into insights
- Creating machine learning models to predict based on transformed data
- Creating integrations with LLMs to label data & generate new datapoints
